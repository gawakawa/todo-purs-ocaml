# Developer Guide

## Commands

- `nix fmt` - Format code
- `nix flake check` - Run checks (format, lint, build, tests)
- `nix build` - Build the project
- `dune exec hello` - Run the executable inside `nix develop`
- `dune utop bin` - Start a REPL (utop) with the project's modules loaded, inside `nix develop`
